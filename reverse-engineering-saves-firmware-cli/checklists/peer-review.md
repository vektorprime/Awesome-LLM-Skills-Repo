# Checklist — Peer Review

Scope/evidence: authorization + versions explicit; original hashes + provenance
present; derived artifacts link parents; sensitive material restricted.
Method: one variable per experiment; identical-state noise measured; entropy
as clue; automation independently validated; read-only/userspace handling.
Spec: offsets/lengths/endian/bases explicit; counts proven by walk; unknowns
stay unknown; variants documented. Parser: truncation + bad lengths rejected;
counts/decompression capped; unknowns preserved; valid + malformed fixtures.
Conclusions: integrity terms not conflated; compat tested multi-sample;
firmware diffs split semantic vs noise; limits + next tests stated.
